# 🧾 readOneExample

## Objetivo

Obtener un ejemplo específico por su ID y compañía.

## Input

- id
- idCompany

## Validaciones

- El ejemplo debe existir en la base de datos
- El id debe ser un UUID válido
- El idCompany debe ser un string válido

## Output

- Ejemplo encontrado con todos sus datos
- Error NotFound si no existe

## Side Effects

- Ninguno

## Estado: DONE
